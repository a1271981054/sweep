# 磁盘面板

在对话输入框上方常驻一块磁盘状态卡片：可用空间、占用条、最近一次扫描的类别明细、自主度与权限状态。

## 为什么是组件而不是图片/HTML

- **图片**做不到自适应：PNG 里写死的文字颜色在深色主题下几乎不可读；
- **HTML 页面**被明确排除：iframe 拿不到宿主主题令牌、深色模式与 locale；
- **React 组件挂进槽位**才是正路：颜色全部由 `currentColor` 派生（`color-mix`），深浅色自动正确，字号与间距跟随宿主。

## 数据来源

卡片不读文件（浏览器读不到），而是轮询 helper 的只读接口：

```
GET http://127.0.0.1:47901/status   每 3 秒
```

返回：磁盘总量/可用、`latest` 快照按类别的汇总、`mode`、`fullDiskAccess`。接口只监听 127.0.0.1、只读、带 CORS 头供页面跨端口读取。

helper 未运行时卡片自动隐藏，不影响其它界面。

## 限制

- 只读展示：按钮式操作（一键清理）尚未实现，清理仍需在对话里确认；
- 仅在 DSH Web 界面出现，其它 MCP 客户端看不到这张卡片；
- 需要 helper 在跑：`sweep helper-install`；
- 完全磁盘访问权限未授权时，右下角会提示，扫描结果也会偏小。
